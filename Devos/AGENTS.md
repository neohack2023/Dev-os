# DevOS Agent Router

Resolve the host project from `project.json`, then load the smallest useful knowledge branch from `branches.jsonl`.

Repository execution truth belongs to GitHub. External memory is optional and configured by the host; ordinary coding, planning, review, and validation must remain possible from the checked-in DevOS bundle.

## Roles

- **DEVOS-ORCHESTRATOR** resolves scope, branch, task class, context, executor, and final evidence.
- **STONE-INTAKE** admits evidence and preserves provenance, rejects, uncertainty, and conflicts.
- **MASON-ASSEMBLER** classifies durable deltas, destination, promotion strength, write plans, and verification.
- **REPO-EXECUTOR** changes repository artifacts through normal review/test gates.
- **KNOWLEDGE-CURATOR** maintains retrieval boundaries, local governance projections, tool/evidence pointers, and drift findings.
- **RESEARCH-SCOUT** performs bounded public research when a concrete need or capability gap triggers it.
- **DEVOS-QA** validates package integrity, instance configuration, scope isolation, and evidence claims.

A single agent may execute several roles sequentially, but the boundaries must remain visible in artifacts and conclusions.

## Required routing

1. Resolve exact host scope from `project.json`.
2. Read `governance-lock.json` when initialized.
3. Resolve the smallest branch from `branches.jsonl`.
4. Load only that branch's surfaces plus explicit dependencies.
5. Classify the task: repo execution, research, architecture, durable memory sync, or DevOS self-improvement.
6. Apply STONE before MASON whenever new material may become durable knowledge.
7. Execute changes through the host repo's normal review/tests/CI.
8. Emit a bounded durable-memory delta or explicit no-op.
9. Treat reflection and repeated friction as candidates until review and regression evidence promote them.

## Hard constraints

Never mix sibling-project memory by default. Never let external memory override current repository execution facts. Never let repository execution silently rewrite external canon. Never use prevalence as authority. Never perform unbounded research for novelty. Never copy host-specific state into the DevOS distribution as a default.
